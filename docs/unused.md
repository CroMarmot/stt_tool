## Vosk 简介

Vosk 是基于 Kaldi 的开源离线语音识别引擎，由俄罗斯 AlphaCepei 团队开发。

### ✅ Vosk 的优点

| 特性               | 说明                                        |
| ------------------ | ------------------------------------------- |
| **⚡ CPU 速度极快** | 3x 实时速度以上，比 Whisper small 快 3-5 倍 |
| **📦 模型体积小**   | 最小模型仅 40MB，大模型也只有 1.5GB         |
| **🔌 纯离线运行**   | 下载模型后完全断网可用                      |
| **💾 内存占用低**   | 大模型也只占用 ~1GB 内存                    |
| **📱 嵌入式支持**   | 可以运行在 ARM、手机等低功耗设备            |

### ❌ Vosk 的致命缺点

| 问题                   | 说明                                   |
| ---------------------- | -------------------------------------- |
| **🔤 中文输出只有词语** | 输出是空格分隔的词语，**没有标点符号** |
| **🚫 无智能断句**       | 不能根据语义分段                       |
| **📝 断句能力弱**       | 基于静音断句，不是基于语义             |
| **🏷️ 专有名词差**       | 人名、品牌、专业术语准确率低           |
| **🌐 中英文混杂差**     | 播客中出现英文术语基本识别错误         |
| **📦 模型分散**         | 每种语言需要单独下载模型               |

## Vosk 技术实现

### 核心流程

```
音频文件
    ↓
ffmpeg 转成 16kHz 单声道 WAV
    ↓
KaldiRecognizer 流式分块识别 (4000 bytes/块)
    ↓
解析 JSON 结果，提取词语
    ↓
调用 Hugging Face BERT 模型单独加标点
    ↓
输出 TXT 和 SRT
```

### 关键代码特性

1. **流式识别**：不一次性加载整个音频到内存
2. **延迟加载标点模型**：第一次使用才加载
3. **自动清理临时文件**：WAV 转码文件自动删除
4. **Progress 进度显示**：Rich 美化终端输出

### 模型下载

中文模型下载地址：https://alphacephei.com/vosk/models

| 模型                     | 体积  | 推荐度 | 备注                 |
| ------------------------ | ----- | ------ | -------------------- |
| vosk-model-cn-0.22       | 1.5GB | ⭐⭐⭐⭐   | 唯一可用的中文大模型 |
| vosk-model-small-cn-0.22 | 42MB  | ❌      | 无时间戳，准确率极低 |

> ⚠️ 必须使用 0.22 大模型，小模型完全不可用！

### 依赖安装

```bash
uv add vosk pydub transformers torch
```

## 什么时候应该用 Vosk？

**只有满足以下所有条件，才考虑用 Vosk：**

1. ✅ 你的 CPU 非常弱（2核4G以下）
2. ✅ 没有任何 NVIDIA GPU
3. ✅ 需要批量处理 1000+ 小时音频
4. ✅ 对准确率要求很低（只要关键词）
5. ✅ 有人工团队做后期校对

**只要有一个不满足，用 Whisper 就是更好的选择！**

## 最后的话

Vosk 是一个**优秀**的轻量级语音识别库，在特定场景下有它的价值。

但对于**播客转文字**这个具体需求：

- **可读性**比内存重要
- **省心**比 DIY 乐趣重要
